# 👁️ THE GOD'S EYE — OBSERVER
## Signal Intelligence Array • Pattern Recognition Engine

Sci-Fi HUD Market Sentiment & Live Level Terminal for **Indian (`NIFTY`, `SENSEX`, `BANKNIFTY`, `GIFT NIFTY`)** and **Worldwide (`GOLD`, `SILVER`, `CRUDEOIL`, `BITCOIN`, `NASDAQ`, `DJI`, `GLOBALRISK`)** markets.

### Project Files
- `index.html` — Main God's Eye Observer HUD interface
- `styles.css` — Sci-Fi glowing cards, corner brackets, and oscilloscope animations
- `app.js` — Always-on live auto-sync engine (Binance 24/7 live crypto API + CoinGecko fallback + multi-proxy Yahoo Finance + Python backend API + GIFT NIFTY 9:15 AM opening cue)
- `market_data.json` — Calibrated benchmark levels and HUD telemetry
- `server.py` — Local Python server with `yfinance` live quote synchronization
- `requirements.txt` & `package.json` — Project dependencies and metadata

### Quick Start
1. **GitHub Pages / Direct Browser**: Push all files to your GitHub repository and enable GitHub Pages (`main` / `/root`), or open `index.html` directly.
2. **Local Python Server**:
   ```bash
   pip install -r requirements.txt
   python3 server.py
   ```
   Open `http://localhost:8000`.
